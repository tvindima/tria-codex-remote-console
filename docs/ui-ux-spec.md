# UI/UX Spec

Visual direction: Vistaulux dark premium.

- Background: deep black-blue gradient.
- Cards: glassmorphism with subtle blur.
- Accent: electric blue.
- Risk colors: green/amber/red.
- Typography: Inter + SF Pro fallback.
- Navigation: fixed bottom glass bar.
- Motion: fast fade/slide transitions, subtle progress animations.

Required screens implemented:

- Login/Pairing
- Dashboard
- Projects
- Threads
- Thread Detail (chat)
- Approvals
- Diffs
- Logs
- Settings
